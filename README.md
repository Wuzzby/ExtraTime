# ExtraTime

ExtraTime is a community-driven app for rating, reviewing, and discussing football matches.

Inspired by Letterboxd, ExtraTime lets fans:
- Rate matches out of 10
- Write short reviews
- Explore iconic matches across competitions
- Follow a rotating Match of the Week

## Core Features

- Match of the Week with editorial context
- Match pages with ratings, reviews, and external links
- Feed and match browser with search and filters
- Local-first storage for fast iteration

## Tech Stack

- Next.js (App Router)
- TypeScript
- Client-side storage (localStorage)
- Deployed on Vercel

## Roadmap (Post–Champions League Final)

- World Cup match expansion
- User accounts and profiles
- Public sharing and social features
- Match timelines and goal-level ratings
